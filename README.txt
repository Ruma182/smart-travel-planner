SERVICE PROVIDER MODULE

Features:
1. Sign Up (create account) and Sign In (login) with hashed passwords.
2. Add/update/delete Travel Package, Hotel and Transport listings with price, availability and image.
3. View/confirm/reject bookings and create booking notifications.
4. Dashboard with listing, booking, revenue and rating performance.
5. View feedback/ratings and reply.
6. Profile view/edit/delete and change password.

Run:
1. Start Apache and MySQL in XAMPP.
2. Open http://localhost/web_tech/Final/service_provider/public/login.php
   (models/Database.php auto-creates the database and tables on first run,
   so importing database.sql is optional.)
3. Click "Sign up here" to create your own provider account.
   There is no demo/dummy account - every user creates their own login.
